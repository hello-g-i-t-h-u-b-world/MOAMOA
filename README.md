# 모아모아 도우미

"한글 모아모아" 미니게임 화면을 실시간으로 읽어서 **오래 살아남기 위한 최적의 배치 순서**를 추천하는 웹 앱입니다.
화면을 읽기만 하고 마우스·키보드 조작은 하지 않습니다.

## 바로 사용하기

설치 없이 브라우저(Chrome/Edge 권장)에서 열면 됩니다: **https://hello-g-i-t-h-u-b-world.github.io/MOAMOA/**

`main` 브랜치에 push하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 자동으로 합니다 (`.github/workflows/deploy.yml`).

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저(Chrome/Edge 권장)에서 표시된 주소(기본 http://localhost:5173)를 엽니다.

## 사용법

1. **화면 공유 시작** → 게임 창(또는 전체 화면)을 선택합니다.
2. 처음 한 번만 **영역 지정**을 합니다. 지정한 영역은 브라우저에 저장됩니다.
   - **보드**: 10×16 격자를 대략 드래그하면 실제 격자선에 **자동으로 맞춥니다**. 미리보기의 칸마다 찍힌 점(채움=블록 색, 빈칸=빈 원)이
     각 칸 가운데에 오는지 확인하세요. 나중에 어긋나면 **격자 자동 맞춤** 버튼을 누릅니다.
   - **조각 1~3**: 각 보유 조각 카드에서 블록이 그려지는 **흰 영역만** 드래그합니다. 글자와 버튼은 빼세요.
   - **점 찍기 개수 / 바꿔 뽑기 개수** (선택): 보유 능력 버튼 오른쪽의 숫자 동그라미를 드래그합니다.
     지정하면 보유 개수를 화면에서 직접 읽습니다(값 옆에 `화면` 표시). 처음 보는 숫자가 나오면
     "몇인가요?" 버튼이 뜨고, 한 번 눌러 알려주면 그 숫자 모양을 기억해서 다음부터 자동으로 읽습니다.
     잘못 알려줬다면 보유 능력 칸 아래의 **숫자 학습 초기화**로 학습한 숫자를 지울 수 있습니다 (기본 내장된 0은 유지).
     숫자는 보드 인식과 별개로 매 순간 읽습니다(조각을 선택해 들고 있는 동안에도). 같은 값이 0.6초 이어질 때만 바꾸고
     (버튼 반짝임·마우스 올림 무시), 안 보이면 마지막 값을 유지합니다.
     화면 배율이 1배 이상이면 배율이 바뀌어도 다시 학습할 필요가 없습니다.
   - **능력 획득까지** (선택): '다음 능력 획득까지 N번'에서 숫자 N만 드래그합니다('번' 글자는 빼고).
     글꼴이 달라 따로 학습합니다(처음 보는 숫자는 1~7 중에서 알려주세요). 이 값으로 아이템이 떨어지는 조각과
     그때 사라지는 가장 오래된 아이템을 계산에 반영합니다. 영역을 지정하지 않으면 보유 능력 칸에서 직접 입력할 수 있습니다.
   - x/y/w/h 숫자 칸에서 미세 조정할 수 있습니다.
   - 영역을 지정한 화면 크기를 기억합니다. 공유 화면 크기가 같은 비율로 바뀌면 영역을 자동으로 맞추고,
     비율이 달라지면(창 공유 ↔ 전체 화면 등) 경고 후 영역 지정 창을 엽니다.
3. 이후 화면이 바뀔 때마다 자동으로 인식하고 계산합니다.
   - **추천 순서**: 놓을 조각, 회전·반전 횟수, 위치(행/열, 1부터 시작, 모양의 왼쪽 위 기준)
   - 계산이 끝나면 **1단계부터** 보드 위 '지금 할 일'에 보여줍니다. 안내대로 놓은 것이 화면에서 확인되면
     **자동으로 다음 단계**로 넘어갑니다. 안내와 다르게 놓으면 남은 조각으로 다시 계산합니다.
     인식이 놓쳤다면 '다음 ▶' 버튼으로 넘길 수 있습니다.
   - 보드의 번호 칸 = 지금 단계에서 블록이 들어갈 자리. 칸은 보유 조각과 **같은 색**으로 표시됩니다.
   - 숫자 색은 보유 조각 칸마다 다릅니다 (1번 빨강 · 2번 남색 · 3번 보라). 보드 칸의 숫자와 추천 순서의 숫자가 같은 색입니다.
     `1단계/2단계…` 탭을 누르면 단계별 보드를 볼 수 있습니다.
   - **점 찍기**와 **바꿔 뽑기** 사용 시점도 함께 추천합니다. 바꿔 뽑기를 써야 할 때는 보드 위에 보라색 안내가 뜨고,
     바꿀 조각 카드에 `⇄ 교체` 표시가 붙습니다 (손패를 다 놓을 수 없으면 빨간 안내).
4. **추천 고정** (기본 켜짐): 블록 3개를 받아 계산이 끝나면, 블록을 옮기는 동안에는 화면과 계산이 멈춥니다.
   다음 블록 3개를 받거나 바꿔 뽑기로 블록이 바뀌면 자동으로 다시 계산합니다.
   추천과 다르게 놓았다면 **다시 계산**을 누르세요. 매번 다시 계산하려면 `추천 고정: 꺼짐`으로 바꿉니다.
   - 게임에서 조각을 클릭해 카드가 노랗게 선택된 동안에는 화면 반영과 계산을 멈춥니다 (`✋ 조각 선택 중`).
     조각을 놓거나 선택을 풀면 그때 화면부터 다시 반영합니다.
   - 바꿔 뽑기 버튼을 눌러 카드가 보라색으로 바뀐 동안에도 멈춥니다 (`⇄ 바꿔 뽑기 중`). 조각을 바꾸면 끝난 뒤 다시 계산합니다.
   - 안내한 자리가 나중에 이미 채워진 칸으로 보이면(아이템 빛에 가려 잘못 본 경우 등) 남은 조각으로 다시 계산합니다.
   - 고정 중에도 1초마다 보드를 확인해, 새로 떨어진 능력(⊙/⇄)은 보드에 깜빡이며 표시하고 기록에 남깁니다.

### 수동 입력 / 테스트

- **이미지 열기**: 게임 스크린샷 파일로 테스트할 수 있습니다.
- 보드 칸을 클릭하면 채우기/비우기, 우클릭하면 아이템 표시(⇄ → ⊙ → 없음)가 바뀝니다.
- 보유 조각은 드롭다운으로 직접 고를 수 있습니다.
- 보유 능력 개수는 자동으로 추적하지만, −/+ 버튼으로 직접 고칠 수도 있습니다.
- 화면 공유 중에 직접 수정하려면 먼저 **일시정지**를 누르세요. 그렇지 않으면 다음 화면 변화 때 인식값으로 덮어씁니다.

## 숫자 학습 데이터 모으기

학습한 숫자는 그 브라우저에만 저장됩니다. 모든 사용자가 학습 없이 읽게 하려면 기본값(`src/capture/digits.json`)에 넣습니다.

1. 보유 능력 칸 아래 **학습 데이터 내보내기** → `moamoa-digits-날짜.json` 파일을 저장소 관리자에게 보냅니다.
   ('화면 저장' 파일에도 학습한 숫자가 함께 들어 있습니다.)
2. 관리자가 검사: `npx tsx scripts/merge-digits.ts 받은파일.json ...`
   - 이미 있는 것은 건너뛰고, 다른 숫자와 거의 같은 모양(잘못 답했을 가능성)은 넣지 않고 알려줍니다.
3. 문제없으면 `--write`를 붙여 저장한 뒤 커밋하면 모든 사용자에게 적용됩니다.

## 잘못 인식될 때

- **다시 계산**: 기억해 둔 인식 상태를 버리고 지금 화면을 처음부터 다시 읽어 계산합니다.
- **화면 저장**: 최근 약 8초의 화면(보드·보유 조각 부분)과 인식 결과를 `moamoa-날짜-시각.json` 파일 하나로 저장합니다.
  잘못 인식된 직후 눌러서 파일을 보내주면 원인을 분석할 수 있습니다.
  (분석: `npx tsx scripts/inspect-capture.ts 파일.json` → 화면을 PNG로 풀고 지금 코드로 다시 인식해 비교)

## 구조

```
src/core/pieces.ts      블록 19종 정의, 회전/반전, 조작 안내
src/core/board.ts       비트보드 (행마다 10비트), 배치, 가로줄 제거
src/core/eval.ts        평가 함수 (구멍, 울퉁불퉁함, 블록별 놓을 자리, 막힌 칸 등)
src/core/search.ts      빔 탐색 (순서 × 회전 × 위치 + 점 찍기), 바꿔 뽑기 기대값 분석
src/core/lookahead.ts   다음 손패 미리 보기 (무작위 다음 손패로 후보 비교, 몬테카를로)
src/core/pool.ts        Web Worker 여러 개에 탐색을 나눠 맡김 (CPU 코어 여러 개 사용)
src/core/solver.worker.ts  Worker 하나가 하는 일 (후보 구하기 / 미리 보기 일부 / 바꿔 뽑기 분석)
src/capture/capture.ts  getDisplayMedia 화면 캡처
src/capture/recognize.ts  보드 칸 색 판별, 아이템 아이콘, 보유 조각 모양 매칭
src/capture/tracker.ts  화면 변화로 아이템 획득/사용 자동 추적
src/ui/main.ts          화면
scripts/sim.ts          자가 대국 시뮬레이터 / 가중치 튜너
```

## 계산 방식

1. **빔 탐색**: 남은 조각 × 회전·반전 × 위치(+ 점 찍기)를 단계마다 모두 만들어 보고, 빠른 평가 점수 상위만 남겨 다음 조각으로 넘어갑니다.
   순서도 자동으로 탐색합니다. 최종 후보는 '블록 종류별로 아직 놓을 자리가 있는지' 등으로 정밀 평가합니다.
2. **다음 손패 미리 보기**: 상위 후보(보통 12개)마다 무작위 다음 손패(보통 48가지)를 실제로 놓아 보고,
   평균이 가장 좋은 후보를 고릅니다. 추천 순서 아래에 '다음 손패를 다 놓을 수 있는 비율'이 표시됩니다.
3. **여러 코어 사용**: 미리 보기는 Web Worker 여러 개(코어 수 − 2, 최대 8)에 나눠 계산합니다.
4. **최고** (고성능 데스크톱용, 탐색 강도 선택에서 고름): 정밀의 약 2.6배를 계산하고 코어를 하나만 남기고 전부 씁니다.
   - 단계별 압축: 후보 30개를 다음 손패 48가지로 걸러 10개 → 96가지 더 → 4개 → 192가지 더 (최종 후보는 336가지로 비교)
   - 위기 보강: 1등 후보도 다음 손패를 다 놓을 확률이 90% 미만이면 192가지를 더 봄
   - 두 손패 앞: 최종 3개 후보는 다음 손패 32가지 × 그다음 손패 16가지까지 놓아 보고 고름 ('연달아 다 놓을 확률' 표시)

자가 대국 비교 (24판, 판당 최대 300턴, 같은 시드 · 이전 규칙: 균등 확률, 블록 5개마다 드롭, 보드 위 개수 제한 없음):

| | 평균 생존 턴 | 게임오버 |
|---|---|---|
| 미리 보기 없음 | 240.3 | 9 / 24판 |
| 미리 보기 (보통) | 300.0 | 0 / 24판 |

계산 시간 (이 개발용 Mac, 8코어 기준): 보통 0.4초 안팎, 최고는 빈 보드 약 6초·중반 1초 안팎. '최고'는 아직 자가 대국으로 측정하지 않았습니다.

## 규칙 (게임 안내 기준)

- **점수**: 배치한 칸 수 + 줄 제거(동시에 지운 줄 수에 따라 300 / 1,200 / 2,700 / 4,800 / 7,500 = 300×줄²) + 능력 획득 50점.
  계산은 이 점수를 직접 반영해 여러 줄을 한 번에 지울 기회를 찾습니다 (생존과 균형, 가중치 `points`).
- **단계**: 제거한 줄 누적 0~30 / 31~60 / 61~100 / 101~150 / 151~ → 1~5단계. 단계가 오를수록 칸 수가 적은 조각이 덜 나옵니다.
  정확한 확률은 공개되지 않아 **가정값**(1단계 균등, 이후 (칸 수)^γ, γ = 0 / 0.25 / 0.5 / 0.75 / 1)을 씁니다.
  화면 공유 중 받은 조각을 단계별로 세어 두고 '학습 데이터 내보내기' 파일에 함께 담으니, 모이면 실제 확률로 바꿀 수 있습니다.
- 보유 능력 칸 맨 위에서 **제거한 줄**(단계)과 **추정 점수**를 보여줍니다. 화면으로 본 줄 제거를 세므로, 게임 중간부터 보기 시작했다면
  줄 수를 직접 고치세요. '초기화'를 누르면 새 게임으로 0부터 셉니다.
- **능력**: 블록 7번 배치마다(점 찍기는 세지 않음) 빈 칸에 생성, 점 찍기 40% · 바꿔 뽑기 60%.
  보드 위 최대 3개(넘치면 가장 먼저 생긴 것부터 사라짐). 7개를 보유하면 더 생성되지 않고, 아이콘 줄을 지워도 획득하지 못하며 아이콘은 남습니다.
- **게임 종료**: 놓을 칸이 없고 보유 능력도 없을 때. 다 놓을 수 없으면 점 찍기를 가진 만큼 모두 써 보고, 바꿔 뽑기가 남아 있으면 덜 위험하게 봅니다.

## 그 밖의 가정

- 판 크기 10×16, 빈 칸 어디에나 배치, 중력 없음, **가로줄만** 제거
- 손패 3개를 모두 놓아야 다음 3개, 놓는 순서 자유, 회전·반전 무제한
- 블록 19종(자음 14 + ·, ㅏ, ㅑ, ㅡ, ㅣ). 등장 확률은 위 '단계' 참고
- 블록을 7개 놓을 때마다 빈 칸에 아이템(⊙ 점 찍기 / ⇄ 바꿔 뽑기)이 떨어지고('다음 능력 획득까지' 7 → 1, 1에서 놓으면 드롭 후 7),
  그 칸이 포함된 줄을 지우면 획득 (최대 7개 보유). 점 찍기는 횟수에 넣지 않음
- 보드 위 아이템은 최대 3개. 새로 떨어질 때 이미 3개면 가장 오래된 것이 사라짐 (같은 조각으로 줄을 지워 먼저 얻으면 사라지지 않음)
- 아이템 칸 위에도 블록을 놓을 수 있고, 아이콘은 블록 위에서도 계속 보임
- 점 찍기로 채운 칸은 연보라색 블록으로 보임
- 아이템 빛·애니메이션에 가려 블록인지 빈칸인지 판단이 안 서는 칸은 직전 상태를 유지함
- 아이템은 1초 이상 같은 자리에 보여야 인정하고, 한 줄 여러 칸이 동시에 아이템처럼 보이면 줄 제거 이펙트로 보고 무시함
- 칸 상태는 일정 시간 같은 상태가 이어질 때만 바꿈: 빈칸→블록 0.5초, 줄 제거 0.5초, 한두 칸만 비어 보이는 경우(아이콘 빛 등) 1.5초. 꽉 찬 줄은 빈 줄로 봄
- 새 블록을 받은 직후(줄 제거 이펙트와 겹치는 순간)에는 화면이 1.2초 동안 변하지 않을 때까지 기다린 뒤 계산
- 게임의 '회전' = 시계방향 90°, '반전' = 좌우 반전

## 개발

```bash
npm test                                   # 단위 테스트 + 실제 스크린샷 인식 테스트
npm run sim -- --games 10 --beam 60        # 자가 대국으로 평균 생존 턴 측정
npm run sim -- --games 24 --turns 300 --beam 150 --look normal --jobs 8   # 미리 보기 켜고 8개 프로세스로 나눠 측정
npx tsx scripts/bench-lookahead.ts         # 미리 보기 속도 측정
npm run sim -- --tune 30 --games 10 --swap 0   # 평가 가중치 튜닝
npx tsx scripts/robustness.ts              # 영역 어긋남·배율·영상 변환에 대한 인식 견고성 실험
npx tsx scripts/digit-robustness.ts        # 보유 능력 숫자 인식의 배율 견고성 실험
```
