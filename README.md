# 모아모아 도우미

"한글 모아모아" 미니게임 화면을 실시간으로 읽어서 **오래 살아남기 위한 최적의 배치 순서**를 추천하는 웹 앱입니다.
화면을 읽기만 하고 마우스·키보드 조작은 하지 않습니다.

## 바로 사용하기

설치 없이 브라우저(Chrome/Edge 권장)에서 열면 됩니다: **https://hello-g-i-t-h-u-b-world.github.io/MOAMOA/**

`main` 브랜치에 push하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 자동으로 합니다 (`.github/workflows/deploy.yml`).

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저(Chrome/Edge 권장)에서 표시된 주소(기본 http://localhost:5173)를 엽니다.

## 사용법

1. **화면 공유 시작** → 게임 창(또는 전체 화면)을 선택합니다.
2. 처음 한 번만 **영역 지정**을 합니다. 지정한 영역은 브라우저에 저장됩니다.
   - **보드**: 10×16 격자의 바깥 테두리에 딱 맞게 드래그합니다. 미리보기에 그려지는 격자선이 칸과 맞는지 확인하세요.
   - **조각 1~3**: 각 보유 조각 카드에서 블록이 그려지는 **흰 영역만** 드래그합니다. 글자와 버튼은 빼세요.
   - **점 찍기 개수 / 바꿔 뽑기 개수** (선택): 보유 능력 버튼 오른쪽의 숫자 동그라미를 드래그합니다.
     지정하면 보유 개수를 화면에서 직접 읽습니다(값 옆에 `화면` 표시). 처음 보는 숫자가 나오면
     "몇인가요?" 버튼이 뜨고, 한 번 눌러 알려주면 그 숫자 모양을 기억해서 다음부터 자동으로 읽습니다.
     잘못 알려줬다면 보유 능력 칸 아래의 **숫자 학습 초기화**로 학습한 숫자를 지울 수 있습니다 (기본 내장된 0은 유지).
   - x/y/w/h 숫자 칸에서 미세 조정할 수 있습니다.
3. 이후 화면이 바뀔 때마다 자동으로 인식하고 계산합니다.
   - **추천 순서**: 놓을 조각, 회전·반전 횟수, 위치(행/열, 1부터 시작, 모양의 왼쪽 위 기준)
   - 보드의 번호 칸 = 각 단계에서 블록이 들어갈 자리. `1단계/2단계…` 탭을 누르면 단계별 보드를 볼 수 있습니다.
   - **점 찍기**와 **바꿔 뽑기** 사용 시점도 함께 추천합니다.
4. **추천 고정** (기본 켜짐): 블록 3개를 받아 계산이 끝나면, 블록을 옮기는 동안에는 화면과 계산이 멈춥니다.
   다음 블록 3개를 받거나 바꿔 뽑기로 블록이 바뀌면 자동으로 다시 계산합니다.
   추천과 다르게 놓았다면 **다시 계산**을 누르세요. 매번 다시 계산하려면 `추천 고정: 꺼짐`으로 바꿉니다.

### 수동 입력 / 테스트

- **이미지 열기**: 게임 스크린샷 파일로 테스트할 수 있습니다.
- 보드 칸을 클릭하면 채우기/비우기, 우클릭하면 아이템 표시(⇄ → ⊙ → 없음)가 바뀝니다.
- 보유 조각은 드롭다운으로 직접 고를 수 있습니다.
- 보유 능력 개수는 자동으로 추적하지만, −/+ 버튼으로 직접 고칠 수도 있습니다.
- 화면 공유 중에 직접 수정하려면 먼저 **일시정지**를 누르세요. 그렇지 않으면 다음 화면 변화 때 인식값으로 덮어씁니다.

## 구조

```
src/core/pieces.ts      블록 19종 정의, 회전/반전, 조작 안내
src/core/board.ts       비트보드 (행마다 10비트), 배치, 가로줄 제거
src/core/eval.ts        평가 함수 (구멍, 울퉁불퉁함, 블록별 놓을 자리, 막힌 칸 등)
src/core/search.ts      빔 탐색 (순서 × 회전 × 위치 + 점 찍기), 바꿔 뽑기 기대값 분석
src/core/solver.worker.ts  Web Worker에서 탐색
src/capture/capture.ts  getDisplayMedia 화면 캡처
src/capture/recognize.ts  보드 칸 색 판별, 아이템 아이콘, 보유 조각 모양 매칭
src/capture/tracker.ts  화면 변화로 아이템 획득/사용 자동 추적
src/ui/main.ts          화면
scripts/sim.ts          자가 대국 시뮬레이터 / 가중치 튜너
```

## 규칙 가정

- 판 크기 10×16, 빈 칸 어디에나 배치, 중력 없음, **가로줄만** 제거
- 손패 3개를 모두 놓아야 다음 3개, 놓는 순서 자유, 회전·반전 무제한
- 블록 19종(자음 14 + ·, ㅏ, ㅑ, ㅡ, ㅣ)이 같은 확률로 등장
- 블록을 일정 횟수 놓을 때마다 빈 칸에 아이템(⊙ 점 찍기 / ⇄ 바꿔 뽑기)이 떨어지고, 그 칸이 포함된 줄을 지우면 획득 (최대 7개 보유)
- 아이템 칸 위에도 블록을 놓을 수 있고, 아이콘은 블록 위에서도 계속 보임
- 게임의 '회전' = 시계방향 90°, '반전' = 좌우 반전

## 개발

```bash
npm test                                   # 단위 테스트 + 실제 스크린샷 인식 테스트
npm run sim -- --games 10 --beam 60        # 자가 대국으로 평균 생존 턴 측정
npm run sim -- --tune 30 --games 10 --swap 0   # 평가 가중치 튜닝
```
